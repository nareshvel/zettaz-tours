Orientation for coding agents. Product truth lives in STRATEGY, ARCHITECTURE, and DECISIONS — not here.

1. Read [../README.md](../README.md) (authority and reading order).
2. Read [MEMORY.md](MEMORY.md) for standing decisions.
3. **Every new session / IDE switch:** read [../HANDOFF/agent-current-sprint.md](../HANDOFF/agent-current-sprint.md) for next task and deploy truth, then [../HANDOFF/cross-ide-agent-resume.md](../HANDOFF/cross-ide-agent-resume.md).
4. Read [../STRATEGY/launch-contract.md](../STRATEGY/launch-contract.md) and [../STRATEGY/delivery.md](../STRATEGY/delivery.md) before writing code.
   Read [../STRATEGY/requirements-plan.md](../STRATEGY/requirements-plan.md) for the current requirements package, proposed permission model and open decisions. Owner authorized mock-data development on September 9; production evidence remains required before go-live.
5. After a session that changes a standing decision, update MEMORY.md (keep it under 200 lines).
6. After a session that changes **next task** or git/deploy truth, update [../HANDOFF/agent-current-sprint.md](../HANDOFF/agent-current-sprint.md) and push.

The full coding-agent prompt is in [../STRATEGY/delivery.md](../STRATEGY/delivery.md).
